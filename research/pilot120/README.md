# Pilot-120 research record

The [GLiNER semantic-router experiment](gliner25_goalfirst_semantic_router_v1/README.md)
tests the frozen T0.7 Goal-First interpretation at the semantic-to-action
boundary. Its text-free results are separate from the earlier raw-source probes.

The [targeted readiness-repair experiment](gliner25_action_readiness_repair_v1/README.md)
starts from the exact 83/120 capability-repaired condition and preserves its
refusal gate while testing the EXECUTE/CLARIFY boundary.

Start with the [120-case index](INDEX.md). Each case file combines the frozen
source and gold with the recorded T0.7 outputs. For example,
[CA-0007](cases/CA-0007.json) contains the command and context, gold labels,
six system predictions, route comparisons, and archived two-judge intent judgments.
The case files are generated by `scripts/release/build_pilot120_cases.py` from
hash-checked inputs; do not edit them by hand.
For a method-to-result walkthrough, use the
[experiment recipes](../../docs/experiments/README.md).

The canonical inputs used by the evaluators remain at
`data/annotations/pilot_120_v1/source_canonical.jsonl` and
`data/annotations/pilot_120_v1/pilot_120_final_gold.jsonl`. Their original
bytes and frozen policy are checked by the case-index builder. The
`frozen/FROZEN_MANIFEST.json` here is the locally verified version with SHA-256
`c61489101bfbc6cf0222538107abd272b50ce59c2f2a4292e95773f686d60230`;
it differs from the older historical Git version. The exact scientific
interpretation and limitations are in [the Pilot-120 guide](../../docs/PILOT120.md).

## Rights and access

These files include upstream-derived text and model outputs that can repeat
it. The rights register in `configs/licences/dataset_licence_register.json`
still marks several exact-artifact redistribution permissions unresolved.
Repository presence is an access and preservation decision by the project
owner, not proof of a public redistribution grant. Review those terms before
further distribution. The repository was observed public on 2026-09-27;
see the [release audit](../../docs/PUBLIC_RELEASE_AUDIT.md). The
[paper map](../../docs/PAPER_REPRODUCIBILITY.md) explains why archived
“official” labels do not establish approved official correctness.
